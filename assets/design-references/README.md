# Approved Figma Make reference

Published reference: https://entry-align-51407368.figma.site/

This is a published Figma Make website, not an editable Figma Design file.
Inspected in a browser on October 20, 2026 for Milestone 1A, including Dashboard
and Finance Management. Finance Management is the primary consistency reference:
standard navy sidebar, pale blue canvas, rounded white cards, blue/aqua accents,
and compact section navigation.

The documented palette in `docs/DESIGN_SYSTEM.md` is implemented in
`packages/ui/src/tokens.css`. The website imports the official accountant PNG
directly from `assets/dolphin/`; the original images are preserved.

This milestone implements the shell and labeled placeholders. Prototype charts,
financial actions, welcome onboarding, and the floating assistant remain future work.
