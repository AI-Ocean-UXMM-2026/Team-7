# User Flows

## Flow 1 — First-Time Setup

1. Seller creates an account or signs in.
2. Seller enters shop information.
3. Seller selects preferred language.
4. Seller completes onboarding.
5. Dashboard opens.

## Flow 2 — Chat to Order

1. Seller opens Messenger in the browser.
2. Seller copies a customer conversation.
3. Seller opens the floating dolphin.
4. Seller selects Chat to Order.
5. Seller pastes conversation.
6. AI analyzes the text.
7. Assistant presents an editable draft.
8. Seller corrects quantities, prices, customer details, or missing fields.
9. Seller confirms and saves.
10. Order appears in Sales Management.

No automatic reading of Messenger messages is allowed.

## Flow 3 — Order to Voucher

1. Seller selects a confirmed order.
2. Seller generates a voucher.
3. Voucher preview appears.
4. Seller downloads, prints, or shares it.
5. If the order changes, a new voucher version is created.
6. Previous versions remain accessible.

## Flow 4 — Screenshot to Order Match

1. Seller opens the floating assistant.
2. Seller selects Screenshot to Order Match.
3. Seller uploads transaction screenshot or manually enters details.
4. AI extracts available information.
5. Seller corrects extraction errors.
6. System proposes matching orders.
7. Seller selects the intended order.
8. Seller verifies received funds through trusted records.
9. Seller explicitly confirms payment.
10. Related order and financial records update.

No screenshot-only automatic payment confirmation.

## Flow 5 — Expense Management

1. Seller opens Finance Management.
2. Seller selects Expenses.
3. Seller enters amount, category, date, and notes.
4. Seller saves.
5. Financial reports update.

## Flow 6 — Dashboard

1. Seller enters Dashboard.
2. Welcome panel appears when appropriate.
3. Seller dismisses it.
4. Existing Good Morning banner remains unchanged.
5. Seller sees Today's Sales, Payments Received, Estimated Profit, Total Orders.
6. Seller filters charts and opens recent orders.

## Primary Buildathon Demo

Messenger conversation → Dolphin → Chat extraction → Editable order → Confirmation → Voucher → Screenshot matching → Seller verification → Financial dashboard.

Use one consistent synthetic seller/customer/order/payment story.
