# Windows floating dolphin assistant

This is the Windows Electron prototype for Milestone 1B. It uses the shared
React UI package and ocean-blue tokens, with the approved dolphin art in
`assets/dolphin/`.

From the repository root, run `pnpm install --frozen-lockfile`, then
`pnpm desktop:dev`. The app is a local, demonstration-only prototype. Chat
extraction and screenshot matching use fixed examples; no AI service, account,
database, transfer verification, or financial write is connected. Details and
release limitations are in `docs/MILESTONE_1B.md`.
